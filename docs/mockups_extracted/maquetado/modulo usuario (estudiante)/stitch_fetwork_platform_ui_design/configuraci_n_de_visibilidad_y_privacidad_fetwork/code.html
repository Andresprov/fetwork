Datos de Seguridad Intocables

Por estricta política institucional de la FET y normativas de ciberseguridad, los siguientes datos NUNCA son expuestos a reclutadores ni terceros:

  • lock Documento de identidad completo (C.C. o T.I. anonimizados en la vista inicial).
  • lock Dirección residencial exacta (únicamente se comparte Ciudad / Municipio: Neiva, Huila).
  • lock Datos y contactos familiares de emergencia (de uso exclusivo para la Decanatura y Bienestar).
  • lock Información financiera y becas de matrícula del sistema Q10.
